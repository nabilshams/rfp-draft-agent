📝 RFP Response Template

Upload a DOCX template used as the base for generated responses. Supports placeholders: {{executive_summary}}, {{solution_overview}}, {{compliance_matrix_summary}}.

⚠ Template Formatting Tips
  • Use Word's built-in Heading styles (Heading 1, Heading 2, Heading 3) for section titles — not just bold or large text.
  • To apply: select the text, then choose Home → Styles → Heading 1/2/3 in Word.
  • Add placeholders like {{executive_summary}} in the body where you want auto-generated content inserted.
  • Sections without Heading styles will not be detected by the parser.
  • Supported placeholders: {{executive_summary}}, {{solution_overview}}, {{compliance_matrix_summary}}
